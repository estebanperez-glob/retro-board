Programs & Teams Guide 🏢

Structure your organization: group teams into programs, manage members, and create retros directly from your team dashboard.

🏢 Open Organization 📖 General guide

🧩 Key concepts

  • Team — a group of people who run retros together (e.g. a Scrum team). Each team has a dashboard with its retros, health score, commitments and leaderboard.
  • Program — a container that groups several teams, like an Agile Release Train in SAFe. Programs enable cross-team leaderboards and dependency tracking.
  • Program Increment (PI) — a timebox for a program (typically 8–12 weeks). Retros can be assigned to a PI for planning-level tracking.
  • Standalone teams — a team does not need a program. Create teams on their own and assign them to a program later.

🔐 Roles & permissions

RoleCan do
🛡 Org managerCreate programs and teams, manage everything, grant org access (from the admin panel).
⭐ RTE (program)Edit/delete the program, add program members, view the program dashboard and cross-team dependencies.
👥 Team leadEdit/delete the team, add/remove members, create retros for the team.
👤 MemberSee the team/program dashboards they belong to.

Org access is granted by a master user from the Admin panel (Grant/Revoke Org). Ask your administrator if you need to create programs or teams.

🚀 Quick start (5 steps)

1 Create the program — in Organization, click New Program and give it a name (e.g. “Payments ART”). Only org managers can create programs.
2 Create the teams — click New Team for each squad. You can assign each team to a program right away, or leave it standalone.
3 Add members — open a team and use Add member. The picker only shows people already in a team of the same program, keeping membership relevant. The first person you add can be promoted to lead.
4 Create retros from the team — in the team dashboard, click New retro: pick a title, sprint and one of the 3 basic templates (Classic, Start/Stop/Continue, Mad/Sad/Glad). The retro is created and assigned to the team automatically.
5 Follow up — check the team and program dashboards: health score, commitments, leaderboards and cross-team dependencies, all in one place.

🛠 Managing programs and teams

  • Edit — use the ✏️ Edit button on a team or program dashboard to rename it.
  • Delete — the 🗑 Delete button removes the team or program but never deletes retros or commitments: they are kept and simply unassigned.
  • Move teams — use Change program on a team dashboard to move it between programs or make it standalone.
  • Program members — RTEs are added from the program dashboard. They can see all program teams and manage the program.

❓ FAQ

Who can create programs and teams?
Org managers (granted by a master in the Admin panel). Team leads can manage their own teams once created.
Why can't I see everyone in the member picker?
By design: for program teams, the picker only offers people already in a team of that program. Standalone teams see all registered users.
What happens to retros if I delete a team or program?
Nothing is lost. Retros and commitments are kept; they just lose the team/program assignment and can be reassigned later.
